# Hoichoi Subscription Performance & Drop-off Analysis

## 📌 Project Overview

This project focuses on analyzing user behavior and subscription performance across the complete digital subscription journey.

The main objective is to identify where users drop off, understand the business impact of those drop-offs, and identify opportunities to improve conversion, payment success, retention, and revenue.

The analysis covers the journey from:

**App Open → Paywall Viewed → Plan Selected → Payment Initiated → Payment Success**

---

## 🎯 Business Objective

The key objectives of this project are:

- Identify major user drop-off points in the subscription funnel
- Measure conversion rates at different stages
- Analyze revenue and potential value at risk
- Compare conversion performance across platforms
- Analyze plan-wise conversion
- Evaluate payment method success rates
- Compare new and returning users
- Identify city-wise drop-off patterns
- Generate actionable business recommendations
